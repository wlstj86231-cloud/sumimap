개인정보처리방침

영농폐기물 집하장 지도는 회원가입이 없고, 이름·연락처·위치를 서버에 모으지 않습니다. 이 방침은 2026년 10월 26일부터 적용합니다.

작성·관리: 제이 미디어 편집팀 (운영 책임: 대표 이정우) · 최종 수정 2026-10-26

1. 서버에 모으는 정보

운영자 서버에 개인정보를 저장하는 기능이 없습니다. 검색어와 고른 지역은 브라우저 안에서만 처리하며 서버로 보내지 않습니다. 사이트를 전달하는 호스팅 사업자(Cloudflare)는 보안과 전송을 위해 IP 주소, 브라우저 정보, 요청 시각 같은 기술 기록을 처리할 수 있습니다. 방문 통계나 분석 도구(Google Analytics 등)는 쓰지 않습니다.

2. 문의할 때 보내는 정보

이메일, 전화, 카카오톡 오픈채팅으로 문의하면 보내 주신 연락처와 내용을 받게 됩니다. 이 정보는 답변과 정정 처리에만 씁니다. 각 수단의 기록은 해당 서비스(Google Gmail, 카카오, 통신사)의 정책에 따라서도 처리됩니다. GitHub 공개 정정 창구에 쓴 글과 계정 정보는 공개되며 GitHub 개인정보처리방침을 따릅니다.

3. 기기에 저장되는 항목

  • sumimap:last-region(브라우저 localStorage): 마지막으로 본 시·도·시·군·읍면 이름. 다음에 “지난번에 본 지역” 단추를 보여 주는 데만 쓰며 서버로 보내지 않습니다.
  • 서비스 워커 캐시: 화면 파일과 시·도별 주소 자료를 기기에 저장해 다시 열 때 빠르게 보여 줍니다.

브라우저 설정에서 sumimap.com의 사이트 데이터를 지우면 모두 삭제됩니다.

4. 주소 복사와 지도 링크

‘주소 복사’는 기기의 클립보드에만 주소를 넣습니다. ‘네이버 지도’, ‘카카오맵’을 누르면 집하장 주소가 검색어로 담긴 해당 지도 서비스로 이동하며, 그 뒤의 처리는 각 회사의 개인정보처리방침을 따릅니다.

5. 광고와 쿠키(Google AdSense)

  • 배출 방법 안내 페이지(/guide/ 아래 7쪽)에는 Google AdSense 광고가 표시될 수 있습니다. 집하장 찾기, 지역별 목록, 소개·정책 페이지에는 광고 코드를 넣지 않습니다. 모든 페이지에는 사이트 소유 확인용 Google AdSense 계정 메타 태그가 있으며, 이 태그는 쿠키를 만들지 않습니다.
  • Google을 포함한 제3자 광고 사업자는 쿠키를 사용해, 이용자가 이 사이트나 다른 웹사이트를 이전에 방문한 기록을 바탕으로 광고를 게재합니다.
  • Google은 광고 쿠키를 사용하여 Google과 파트너가 이 사이트 및 인터넷의 다른 사이트 방문 기록을 바탕으로 이용자에게 광고를 게재할 수 있도록 합니다.
  • 이용자는 Google 광고 설정(adssettings.google.com)에서 맞춤 광고를 사용 중지할 수 있습니다. 브라우저에서 쿠키를 차단하거나 지워도 됩니다.
