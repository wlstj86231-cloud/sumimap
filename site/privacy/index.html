스미맵은 자체 서버에 사용자의 계정, 연락처, 위치 기록 또는 지도 사용 내역을 저장하지 않습니다.

스미맵 서버에서 수집하는 정보

스미맵은 회원가입과 로그인 기능을 제공하지 않으며, 자체 서버에 사용자 프로필, 문의 내용, 정확한 위치, 저장한 장소 또는 최근 본 장소를 수집·보관하는 기능을 운영하지 않습니다. 지도 화면의 장소 평가는 사용자가 입력한 내용을 서버로 전송해 자동 공개하는 구조가 아닙니다.

다만 웹사이트 제공과 보안을 담당하는 호스팅 사업자는 통상적인 접속 과정에서 IP 주소, 브라우저 정보, 요청 시각과 같은 기술 로그를 일시적으로 처리할 수 있습니다.

브라우저 안에 저장되는 항목

언어 설정, 저장한 확인 포인트와 최근 본 확인 포인트는 사용 중인 브라우저의 로컬 저장소(localStorage)에만 남을 수 있습니다. 이 데이터는 스미맵 계정과 연결되지 않으며 다른 기기로 자동 동기화되지 않습니다.

브라우저의 사이트 데이터 삭제 기능에서 sumimap.com 데이터를 지우거나, 개발자 도구의 저장소에서 sumimap:으로 시작하는 항목을 삭제하면 초기화할 수 있습니다. 브라우저 데이터를 지우면 복구할 수 없습니다.

위치 권한 사용

사용자가 ‘현재 위치’ 버튼을 누르고 브라우저 권한을 허용한 경우에만 기기의 위치를 읽습니다. 위치는 화면에서 지도 중심과 후보까지의 거리를 계산하는 동안 사용하며, 스미맵 자체 서버에 저장하거나 이동 경로를 추적하지 않습니다. 권한은 브라우저 또는 기기 설정에서 언제든 철회할 수 있습니다.

외부 지도와 링크

지도 표시에는 OpenStreetMap 기반 지도 데이터와 CARTO 타일을 사용합니다. 검색은 브라우저에 포함된 지역 기준점만 대상으로 하며 검색어를 스미맵 서버나 지오코딩 서비스에 보내지 않습니다. 길찾기 버튼을 누르면 목적지 좌표가 포함된 Google Maps 페이지로 이동합니다. 외부 서비스는 각자의 개인정보처리방침에 따라 IP 주소, 브라우저 정보와 요청 내용을 처리할 수 있습니다.

Google 광고와 쿠키

일부 가이드 페이지에는 Google 광고 코드가 포함될 수 있습니다. Google을 포함한 제3자 사업자는 광고 제공과 측정을 위해 쿠키를 설정하거나 읽고, 웹 비콘, IP 주소 또는 기타 식별자를 사용할 수 있습니다. 사용자의 이전 방문을 바탕으로 맞춤 광고가 표시될 수 있습니다.

Google 파트너 사이트에서의 정보 사용 방식과 Google 광고 설정에서 자세한 내용과 맞춤 광고 선택 항목을 확인할 수 있습니다.

문의와 정정 요청

스미맵 문의는 공개 GitHub Issues를 사용합니다. GitHub로 이동한 뒤 입력한 제목, 본문, 첨부 파일과 계정 정보는 공개될 수 있으며 GitHub의 정책에 따라 처리됩니다. 연락처, 신분증, 예약번호, 영수증, 정확한 사적 위치 등 개인정보나 민감정보를 작성하지 마세요.
