가공 기록

  • 원본 CSV(CP949)의 시도·시군구·공동집하장명·소재지 열만 UTF-8 TSV로 바꿨습니다. 원본·변환본의 SHA-256 해시를 기록해 두고, 변환본 해시와 행 수는 점검(npm run check) 때마다 다시 확인합니다.
  • 화면 표시: 이름이 빈 16건은 ‘이름 미등록’, 소재지에 지역명이 빠진 1건은 시·도·시·군·구를 앞에 붙임, 지역명이 두 번 적힌 3건은 한 번만 표시. 완전히 같은 줄 137건은 합치지 않았습니다.
  • 읍·면·동 묶음: 주소 글자에서 첫 읍·면·동을 읽었습니다. 의성군처럼 ‘면’ 없이 적은 이름은 적힌 그대로 쓰고, 같은 시·군에 ‘○○면’ 표기가 있으면 그쪽으로 합쳤습니다. 읍·면이 없는 711건은 ‘읍·면 표기 없음’으로 모았습니다.
  • 시·도 페이지의 ‘주소 자료에서 읽히는 것’은 같은 파일에서 도로 이름 주소(‘○○로 12’ 꼴), ‘산’ 지번, 괄호 설명, 이름에 든 낱말을 글자 규칙으로 센 값입니다. 사람이 한 줄씩 판정한 값이 아니라 근삿값일 수 있습니다.
  • 찾기 화면 자료: 위 TSV를 시·도별 JSON 파일로 나눠 필요한 지역만 내려받게 했습니다. 내용은 TSV와 같습니다. 가공 TSV 내려받기

재현 방법과 해시 값은 저장소의 docs/data-sources/farm-waste-collection-2025.md에 있습니다.
