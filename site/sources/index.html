지도 마커를 읽는 기준

스미맵의 지도 마커는 배터리가 부족하거나, 화장실이 급하거나, 비를 피해야 하는 순간에 무엇을 먼저 확인할지 보여주는 상황별 확인 포인트입니다. 특정 시설의 이용 가능성을 보증하는 표시, 정부나 교통기관의 공식 시설 목록, 실시간 혼잡도 또는 실시간 제보 인증을 뜻하지 않습니다.

시설명, 출구, 운영시간, 화장실·엘리베이터 같은 설비는 아래 공식 원문에서 다시 확인합니다. 카페 콘센트, 매장 화장실, 한국어 응대처럼 지점과 근무자에 따라 달라지는 정보는 현장 표지와 직원 안내를 우선하며, 공식 확인 범위를 넘겨 단정하지 않습니다.

  • sourceUpdatedAt: 원문 기관이 페이지나 데이터에 표시한 갱신일입니다. 날짜가 없으면 “원문 미표기”라고 적습니다.
  • checkedAt: 스미맵 편집자가 해당 원문 URL과 핵심 범위를 다시 확인한 날짜입니다.
  • 두 날짜는 같은 뜻이 아닙니다. checkedAt이 최근이어도 원문 데이터 자체가 오래됐을 수 있으므로 원문의 기준일과 주의 문구를 함께 읽습니다.
