모든 주소와 배출 방법 설명은 아래 공식 원문에서 왔습니다. 원문 기관의 갱신일과 운영자가 다시 확인한 날(자료 대조일)을 구분해 적습니다.

공동집하장 주소 자료

  • 원문: 한국환경공단_전국 영농폐기물 공동집하장 위치_20250827 (공공데이터포털, 제공기관 한국환경공단, 이용허락범위 제한 없음)
  • 사용 중인 파일: 2025년 8월 27일 기준, 9,553행. 원본 CSV(CP949)의 시도·시군구·공동집하장명·소재지 열만 UTF-8 TSV로 바꿨고, 원본·변환본의 SHA-256 해시를 기록해 두고, 변환본 해시는 점검(npm run check) 때마다 다시 확인합니다.
  • 포털 최신 표시(2026-10-26 확인): 파일명 기준일·수정일 2026년 9월 29일, 전체 행 9,553, 업데이트 주기 연간, 차기 등록 예정일 2027년 10월 4일. 새 파일과의 전체 대조는 아직 하지 않았습니다.
  • 화면 표시: 이름이 빈 16건은 ‘이름 미등록’, 소재지에 지역명이 빠진 1건은 시·도·시·군·구를 앞에 붙임, 지역명이 두 번 적힌 3건은 한 번만 표시. 완전히 같은 줄 137건은 합치지 않았습니다.
  • 읍·면·동 묶음: 주소 글자에서 첫 읍·면·동을 읽었습니다. 의성군처럼 ‘면’ 없이 적은 이름은 적힌 그대로 쓰고, 같은 시·군에 ‘○○면’ 표기가 있으면 그쪽으로 합쳤습니다. 읍·면이 없는 711건은 ‘읍·면 표기 없음’으로 모았습니다.
  • 찾기 화면 자료: 위 TSV를 시·도별 JSON 파일로 나눠 필요한 지역만 내려받게 했습니다. 내용은 TSV와 같습니다. 가공 TSV 내려받기

재현 방법과 해시 값은 저장소의 docs/data-sources/farm-waste-collection-2025.md에 있습니다.
