    주소를 확인한 뒤의 순서

    1. 집하장 이름보다 소재지 주소를 먼저 보고, 지도 검색 결과가 같은 위치를 가리키는지 대조합니다. 주소만으로 정확한 출입구를 알 수는 없습니다.
    2. 관할 읍·면 또는 시·군 환경 담당 부서에 연락해 현재 운영 여부와 배출 가능한 품목, 수거 일정, 반입 방법을 묻습니다. 공개 파일에는 전화번호·운영시간·품목이 없습니다.
    3. 폐비닐과 사용을 마친 농약용기는 재질·종류별 분리 기준을 확인합니다. 남은 농약이나 일반 폐기물을 이 주소에 곧바로 가져가도 된다는 뜻은 아닙니다.

    배출 품목을 어떻게 구분할지 궁금하다면 보리장터의 영농폐기물 배출 방법 안내를 참고하세요. 주소 검색 결과와 배출 기준은 서로 다른 정보입니다.

    공식 원문과 자료의 한계

    위 주소는 공공데이터포털의 한국환경공단 전국 영농폐기물 공동집하장 위치 자료를 가공한 것입니다. 원본 제목의 기준일은 2025-08-27이고, 포털의 페이지 수정일은 2026-04-20입니다. 포털 설명에 따르면 지방자치단체가 매년 자료를 제출합니다. 원본의 시도·시군구·이름·소재지 네 열만 사용했으며, 이름이 빈 16개 행은 ‘이름 미등록’으로 표시했습니다. 완전히 같은 행이 반복된 경우도 합치지 않아 등록 행 수는 서로 다른 시설 수가 아닙니다. 소재지에 지역명이 빠진 1개 행은 시도·시군구 열을 앞에 붙여 주소를 표시합니다.
