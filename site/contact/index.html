공개 문의 창구

스미맵 GitHub에서 새 문의 만들기

GitHub 계정 로그인이 필요할 수 있습니다. 이슈의 제목, 본문, 첨부 파일과 작성자 계정은 인터넷에 공개될 수 있습니다.

개인정보를 작성하지 마세요

이름, 이메일, 전화번호, 신분증, 예약번호, 영수증, 얼굴 사진, 계정 정보, 정확한 사적 위치 또는 그 밖의 민감정보를 올리지 마세요. 현재 비공개 문의나 개인정보를 받는 별도 메일 창구는 운영하지 않습니다.

정정 요청에 포함하면 좋은 내용

  • 해당 스미맵 페이지 주소와 장소명
  • 수정이 필요한 문장 또는 위치
  • 바르게 고칠 내용과 변경 이유
  • 지자체, 교통기관, 공공기관 또는 시설 운영자의 공식 링크

개인 블로그나 커뮤니티 게시물만으로는 즉시 수정하지 않을 수 있습니다. 공식 자료와 대조한 뒤 반영 여부를 결정합니다.

접수 가능한 항목

  • 잘못된 장소명, 위치, 영업 상태 또는 이용 조건
  • 끊어진 출처 링크와 오래된 정보
  • 화면 표시, 모바일 조작, 번역 또는 접근성 오류
  • 이용약관, 개인정보 처리와 편집 원칙에 관한 질문

긴급 상황에는 사용하지 마세요

GitHub 문의는 즉시 대응하는 창구가 아닙니다. 범죄·위험 상황은 일본 경찰 110, 화재·구급은 119 등 공식 긴급 연락처를 이용하세요.
