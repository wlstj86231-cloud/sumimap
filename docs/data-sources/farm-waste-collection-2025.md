- 이용 조건: 공공데이터포털의 “이용허락범위 제한 없음” 표시를 확인
- 보조 원문: [한국환경공단 영농폐기물 수거·처리사업](https://www.keco.or.kr/web/lay1/S1T185C1072/contents.do)
- 공식 CSV: 906,703 bytes, SHA-256 `38714DD249FBA836E8BAA37D680C761086A4AD3ABD9A18B94D35251E8185DF65`. 검증 사본은 이 작업의 `artifacts/sumimap-farm-waste-audit/official-2025-collection-sites.csv`에 보관.
- 데이터 변환: `scripts/verify-farm-waste-data.mjs`가 원본 CP949 CSV의 `시도`, `시군구`, `공동집하장명`, `소재지` 열만 UTF-8 TSV로 변환한다. 이름이 비어 있던 16행은 `이름 미등록`으로 표기한다. 원본과 변환본 해시가 검토한 스냅샷과 같아야 저장한다.
- 사이트 배포 파일: `site/data/farm-waste-collection-sites-2025.tsv`, 헤더 1행과 데이터 9,553행, LF 정규화 948,833 bytes, SHA-256 `91DE4E2BA801E647E38E3F3819186B4339FA0369A2488BC56483878E4EE784EE`.

재현: 공공데이터포털의 같은 원본 CSV를 내려받아 `npm run data:import -- "<원본 CSV 절대 경로>"`를 실행한다. 이미 배포할 TSV가 있으면 `npm run data:verify -- "<원본 CSV 절대 경로>"`로 원본→변환 결과까지 대조한다. `npm run check`는 원본 파일 없이 배포 TSV의 해시·형식·행 수를 검증한다. CSV 디코딩에는 개발 의존성 `iconv-lite`의 CP949 매핑을 사용한다. Node 기본 `TextDecoder("euc-kr", { fatal: true })`는 원본 2글자를 거부하므로 그 방법으로 재생성하지 않는다.

## 편집·표시 범위

이 페이지는 시·도 및 시·군·구별 주소 후보를 골라 최대 세 곳을 나란히 비교하는 도구다. Boribay의 영농폐기물 배출 방법 안내와 문장·구성을 복제하지 않는다. 원본에는 완전 동일 행의 중복 그룹 130개와 중복 추가 행 137개가 있다. 이 행을 임의로 통합하지 않으며, 9,553행을 현재 가동 시설 수나 서로 다른 시설 수라고 부르지 않는다. 별도 좌표 데이터가 없어 점 지도와 거리순 정렬을 만들지 않는다. 주소의 지도 검색 결과도 시설 출입구의 검증된 위치로 취급하지 않는다.

원본 `소재지`에서 시도·시군구가 모두 빠진 행이 1개(서귀포시 평지동 공동집하장)다. 화면 주소와 지도 검색어에는 해당 행의 `시도`, `시군구` 열을 앞에 붙인다. 이는 원본 열을 활용한 문맥 보강이며 좌표 검증이나 주소 정정을 뜻하지 않는다. 원본의 오탈자 가능성도 임의로 고치지 않는다.

원본에 운영 여부, 당일 수거 가능 품목, 수거 시간, 담당자 연락처가 없으므로 방문 전 관할 읍·면 행정복지센터 또는 시·군 환경 담당 부서에 확인하도록 안내한다. 한국환경공단 원문과 주소가 다르다는 제보는 공개 정정 창구에서 원문 URL과 행을 대조하고, 자료 자체의 오류는 제공기관에 전달해야 한다.
